# בונה סימולציות הוראה

אתר סטטי שבונה ארבעה סוגי פרומפטים לסימולציית הוראה במערכת הפטל:
1. מנהל השיח
2. המנחה
3. הנחיות משותפות לכל התלמידים
4. פרומפט דמות לכל תלמיד/ה (1–5)

החלקים הקבועים כתובים ב־`js/prompts.js`. מאגר האישיויות נמצא ב־`js/personas.js`.

## הסיסמה

הסיסמה היא 2221. היא שמורה כ־SHA-256 בקובץ `js/config.js`.
זה מסך כניסה, לא אבטחה: כל מי שפותח את הקוד ב־GitHub רואה את הפרומפטים.

## פרסום ב־GitHub Pages

1. מעלים את התיקייה `sim-prompt-builder` כ־repo.
2. ב־Settings → Pages בוחרים: Deploy from a branch → `main` → `/ (root)`.
3. אחרי דקה הכתובת תופיע שם.

## חיבור השמירה המשותפת (פעם אחת)

כל עוד השמירה לא מחוברת, תרגילים נשמרים רק בדפדפן של מי ששמר/ה.

1. פותחים Google Sheet חדש.
2. Extensions → Apps Script. מוחקים את מה שיש, ומדביקים את התוכן של `apps-script/Code.gs`.
3. Deploy → New deployment → סוג: **Web app**.
   - Execute as: **Me**
   - Who has access: **Anyone**
4. מאשרים את ההרשאות ומעתיקים את ה־Web app URL (נגמר ב־`/exec`).
5. מדביקים אותו ב־`js/config.js`, בשדה `SAVE_ENDPOINT`, ומעלים שוב ל־GitHub.

התרגילים נשמרים בגיליון בלשונית `exercises`. כדי למחוק תרגיל, מוחקים את השורה בגיליון.
